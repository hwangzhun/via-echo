# viaecho 字体与图标规范

## 全局字号审计

原样式共有 12 种固定字号（9、10、11、12、13、14、15、16、17、22、25、36 px）和 4 组 `clamp()` 字号。键名在主窗使用 10–13 px、配置窗固定 10 px；旋钮名称也分别使用 9–11 px 与 9 px。同一种信息随窗口和视口变化，不利于一致阅读。

现在两个窗口共用 `src/styles.css` 中的四个字号变量，不在组件或响应式断点中重新定义字号：

| 变量 | 大小 | 使用范围 |
| --- | --- | --- |
| `--text-caption` | 12 px | 两窗的按键、旋钮按压与旋转名称；层标签、状态、说明、QMK 代码 |
| `--text-body` | 13 px | 正文、导航、表单输入、按钮和设置项 |
| `--text-heading` | 15 px | 两窗品牌、分组标题、编辑栏标题 |
| `--text-title` | 20 px | 配置页面主标题 |

字体栈统一为 Segoe UI Variable / Segoe UI / Microsoft YaHei UI / Noto Sans CJK SC / system-ui。正文行高 1.6，紧凑键名与标题行高 1.3；字重只使用 400、500、600。窗口缩放改变布局与空间，不改变字号。长按键名称最多显示两行，旋钮名称截断时可悬停查看完整文案。

## 图标与窗口

- 界面图标使用 `@phosphor-icons/react` 的 regular SVG，通过 `src/icons.tsx` 按组件导入；旧键位数据中的符号提示转换为同一套 SVG，保留原存储格式。
- 图标尺寸独立于字号：旋转方向 12 px、标题栏和键帽 16 px、导航 18 px、空状态 32 px。
- 两窗共用 `WindowTitlebar`：高度 52 px、控制按钮 28×28 px、窗口圆角 18 px。
- 配置窗关闭按钮沿用未保存修改保护，系统关闭事件也使用同一逻辑。
- 旋钮的逆时针名称在左、顺时针名称在右，位于同一条水平线上；两侧各有 Phosphor 方向图标。

## 品牌、状态与缩放

- 产品展示名统一为 `viaecho`，图标源文件是 `logo/viaecho.svg`。`npm run icons` 用 Tauri 图标工具生成 PNG 和多尺寸 ICO；源码摘要未变时复用已有结果。
- 关于页面用浅色底承载原始 logo，保证深浅主题下都能读出原有深色字标。
- `StatusIndicator` 只使用固定绿 `#45b97c`、灰 `#7d8796`、红 `#e36b70`。无遥测设备仍属于已连接；连接中属于尚未连接。强调色不参与连接状态着色。
- 配置页键盘由弹性容器和 ResizeObserver 同时约束宽、高，保持物理布局比例。小窗口中页面可滚动，编辑栏保持最小可读宽度。
- 主窗底部左侧从布局元数据读取“键盘型号：XXXX”，右侧按需要显示手动预览层。
