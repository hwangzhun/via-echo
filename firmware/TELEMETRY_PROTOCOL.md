# viaecho 遥测协议 v1

viaecho 电脑端通过 VIA Raw HID 向键盘固件查询实时状态。该通道只读取状态，不会修改 VIA 键位或改变键盘原有的输出行为。

## 请求

电脑端发送标准 VIA `CustomMenuGetValue` 请求：

- VIA 命令：`id_custom_get_value` (`0x08`)
- channel：`0x00`
- value ID：`0x42`
- HID 报告长度：32 字节（写入时另带 report ID）

## 回应格式

固件保留命令、channel 和 value ID 前缀，然后在同一个 32 字节 VIA 报告中返回：

| 字节位置 | 含义 |
| --- | --- |
| 0 | VIA 命令 `0x08` |
| 1 | channel `0x00` |
| 2 | value ID `0x42` |
| 3 | 遥测协议版本，当前为 `0x01` |
| 4 | 当前最高活动层，范围 `0..3` |
| 5..8 | 矩阵第 0..3 行的按下位图 |
| 9..11 | 旋钮 0..2 的 8 位循环计数器 |
| 12..31 | 保留，当前填充为 `0` |

## 矩阵位图

每个矩阵行字节使用位 0..4：

- 第 0..3 列是该行的 4 个普通按键。
- 第 4 列在第 0..2 行分别是旋钮 0..2 的按压开关。
- 某一位为 `1` 表示对应按键正在按下。

例如，第 1 行数值为 `0b00010010`，表示该行的普通键第 1 列和旋钮 1 的中心按键正在同时按下。

## 旋钮计数器

- 顺时针旋转时计数器加 `1`。
- 逆时针旋转时计数器减 `1`。
- 计数器是 8 位循环值，溢出后自动回绕。
- 电脑端用带符号的回绕减法比较前后两次读数，因此从 `255` 回绕到 `0` 仍会被正确识别为一次顺时针旋转。

计数发生在 QMK 动态编码器映射产生的合成按键事件中。更新计数器后事件仍继续进入 QMK 的正常处理流程，所以 VIA 中配置的旋钮动作不受影响。

## 版本处理

电脑端只解析协议版本 `1`。如果固件返回未知版本，电脑端会将设备标记为“固件需升级”，但仍可读取 VIA 键位并手动查看四层，不会把未知数据当作按键状态解析。
